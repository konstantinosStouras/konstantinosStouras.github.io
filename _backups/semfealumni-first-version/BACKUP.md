# Backup: the first version of the SEMFE Alumni site

This folder is a BACKUP, kept on purpose (owner, 1 October 2026).

* The live site is **https://semfealumni.gr/**, built from the repository
  **konstantinosStouras/semfealumni** (branch `main`). Make every change there.
* This copy is NOT on the web: GitHub Pages (Jekyll) does not publish folders
  whose name begins with `_`, and this one sits under `_backups/`.
* Never deploy it. Its `.firebaserc` still says `PASTE_PROJECT_ID`, so its
  `check-project.mjs` refuses every Firebase deploy.
* Do not move it back to `semfealumni/` at the top of this repository: that
  would publish the old pages at stouras.com/semfealumni/.
